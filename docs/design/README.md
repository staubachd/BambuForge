# Design reference

The "Kammer" redesign was drafted on a design canvas before it was built. The
drafts are kept here as the reference the live pages were built against. The
**Printer › Now** page:

- [`jetzt-entwurf.html`](jetzt-entwurf.html) – the draft as static HTML (open it
  in a browser; all figures in it are sample data)
- [`jetzt-entwurf.png`](jetzt-entwurf.png) – the same, as a picture

The other pages, one static HTML file each: `entwurf-*.html` (Hardware, USB
drive, raw data, live view, history, statistics, filament inventory and
purchases, maintenance, notes, MakerWorld list and model page, settings, setup
wizard, and the Now page at phone width).

Where the built page differs, the built page is right: it shows only what the
app actually knows, and leaves out a panel rather than fill it with a guess.
